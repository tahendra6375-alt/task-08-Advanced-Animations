# Task 09: Advanced Animations

A micro-frontend interaction layout showing off fluid performance-driven custom timeline animations, entry effects, and responsive visual states.

## Features
* **Keyframe Motion Graphics:** Smooth custom keyframe choreography for landing section transitions and entry triggers.
* **State Transitions:** Rich layout modifications utilizing CSS transitions triggered on interactive mouse hovers or focus highlights.
* **Performance Tuning:** Uses specialized hardware-accelerated transforms (`transform`, `opacity`) to ensure solid, stutter-free execution frame rates.

## Tech Stack
* HTML5 (Element canvas layer)
* CSS3 (Keyframes, Animations, Cubic-Bezier Easings)
* Vanilla JavaScript (Scroll trigger/State class changes)

## How to Run
Launch `index.html` locally and interact with the elements to see the transition keyframe animations in motion.
